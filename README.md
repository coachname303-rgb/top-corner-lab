# Top Corner Lab

แผนที่สกิลหลายมิติ ช่วยให้คุณเห็นว่าตัวเองเก่งตรงไหนเมื่อมองหลายด้านพร้อมกัน
ไม่ต้องเก่งที่สุดในแกนเดียว แค่หา "พื้นที่" ที่ส่วนผสมของสกิลของคุณไม่มีใครเหมือน
แล้วสู้ในสนามที่คุณเก่ง และที่สำคัญ… **Never give up**

**เล่นได้ที่:** https://coachname303-rgb.github.io/top-corner-lab/

## ทำอะไรได้บ้าง

- สร้างแกนสกิลเองได้สูงสุด 8 แกน ตั้งชื่อ เปิด/ปิด และให้คะแนน 0–100
- เพิ่มคนหรือจุดเปรียบเทียบได้ไม่จำกัด แต่ละจุดเปิด/ปิดบนกราฟได้
- มุมมองเปลี่ยนตามจำนวนแกน: เส้น (1) · สี่เหลี่ยม (2) · ลูกบาศก์ 3D (3) · ใยแมงมุม (4+) · ทรงกลม 3D ที่หมุนดูได้
- **% reach** บอกว่าคุณไปได้กี่เปอร์เซ็นต์ของทางสู่ Top (100 ทุกแกน)
- **เวลาเรียนรู้:** แบ่งชั่วโมงต่อสัปดาห์ให้แต่ละแกน แล้วเลื่อนดูอนาคต 0–24 เดือน
- เซฟกราฟเป็นรูปภาพได้
- ใช้ได้ทั้งคอม มือถือ และ iPad

แกนเริ่มต้นสำหรับเด็กมหาลัย: วิชาการ · สกิลใช้งานจริง · สื่อสาร & คอนเนคชั่น · ประสบการณ์จริง · สุขภาพกายใจ

> การฉายอนาคตใช้โมเดลคร่าวๆ ที่ยิ่งคะแนนสูงยิ่งขึ้นช้า ไว้ดูทิศทาง ไม่ใช่คำทำนายจริง

## เปิดใช้งานในเครื่อง

ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย (ต้องต่ออินเทอร์เน็ตเพื่อโหลด Three.js และฟอนต์) ข้อมูลที่กรอกเก็บไว้ในเบราว์เซอร์ของแต่ละคน
